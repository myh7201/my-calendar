# 筆記與日記 v45.2

- 手機筆記本、回顧、設定改為完整頁面；回顧包含照片瀏覽。
- 首頁採單欄卡片、四種類型、日期範圍與篩選。單一新增入口可選日記、筆記、隨手記。
- 手機編輯底部改為插入、格式、資料、模板、更多。日期、心情、精力、封面和天氣移到資料入口。
- 返回依序處理鍵盤、面板、編輯、閱讀、原清單與上層頁面；搜尋條件和捲動位置保留。
- 自動儲存區分本機與同步狀態；增加帳號隔離的 IndexedDB 草稿日誌與中斷復原。
- 卡片長按或省略按鈕可置頂、移動、歸檔、多選與刪除；刪除可撤銷，回收站仍可還原。
- 手機隱藏捲動條並保留觸控捲動；桌面保留捲動條。
- Android 增加前景單次原生定位，允許概略位置，取消與逾時會停止請求。舊 APK 仍可使用瀏覽器定位或手動輸入。
- 天氣直接連線失敗時，經日曆唯讀服務向固定 Open-Meteo 來源重試。只傳概略座標，不傳帳號權杖；預覽確認後才寫入記錄。

沿用既有 GitHub 登入、私人資料庫同步、日曆及任務儲存格式。沒有正式資料遷移或重設。

定位與天氣只在使用者按「使用晴訊」後要求，不要求背景定位。資料為目前模式估算，不代表日記日期的歷史實測。資料來源：[Open-Meteo](https://open-meteo.com/) / [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。
