# 筆記介面更新（2026-11-16）

- 新增內容先選「日記」或「筆記」；獨立「隨手記」可快速輸入。
- 隨手記仍以原本的 note 儲存，附加 capture=quick；舊記錄不需遷移。
- 所有記錄、日記、筆記、隨手記可分別瀏覽；支援清單／雙欄卡片。
- 開啟既有記錄先進入閱讀，按「編輯」修改，按「完成」儲存並返回閱讀。
- 筆記區使用日曆紫色，保留獨立導航；返回日曆才顯示日曆導航。
- 天氣和地點可手動輸入，或透過晴訊筆記模組定位、預覽後確認加入。
- 晴訊網頁模組沿用本專案使用的 SkySignal v65 WMO 天氣描述及 Open-Meteo 來源，移植為瀏覽器模組；不包含晴訊原生 App 的全部預報、警告或地圖功能。
- 自動取得的是目前的模式天氣估算，明示資料時間；不把它視為歷史實測。
- 不會在開啟筆記時自動定位，也不會在查詢失敗時改寫既有天氣。
- 天氣快照與隨手記屬性保留在原有 richNote 資料內，沿用既有 GitHub 帳號同步、備份與衝突處理。
- 不更動日曆事件、任務、帳號登入、後端或資料內容。

設計流程參考 Jotsy 與 Floral Notepaper，未引入其程式碼。原有編輯器及第三方授權見 THIRD_PARTY_LICENSES。
